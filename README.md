### Kamran Heydarov

Chemoinformatics M.Sc. student at the University of Strasbourg.
I build QSPR models and open-source tools for molecular data, with a focus on ionic liquids and sustainable solvents.

[Website](https://kammmran.github.io) · [CV](https://kammmran.github.io/cv.html) · [PyPI](https://pypi.org/project/pyionics/)

<br>

**Projects**

- [pyionics](https://github.com/kammmran/pyionics): NIST ILThermo ionic liquid data in Python
- [ENodorIM](https://github.com/kammmran/ENodorIM): from molecule to smell, an olfaction simulator
- [ILQSPR](https://github.com/kammmran/qspr-il-density-refractive-index): density and refractive index of ionic liquid mixtures
- [marimo4obs](https://github.com/kammmran/marimo4obs): marimo notebooks inside Obsidian
- [collab-kit](https://github.com/kammmran/collab-kit): contribution rules for humans and AI agents
- [PyDOOM-DL](https://github.com/kammmran/PyDOOM-DL): a raycasting shooter built for RL agents

**Tools**

Python · RDKit · scikit-learn · XGBoost · pandas · KNIME · TypeScript · React · Django
