### 🧪 About me

I work where physical chemistry, molecular modelling and machine learning meet. My focus is the full **QSPR workflow**: curating experimental data from chemical databases, computing and selecting molecular descriptors, training and validating ensemble models, and turning them into documented tools that non-specialists can use.

- 🔬 Research interests: QSPR & ML for physicochemical properties, ionic liquids and sustainable solvents, chemical data curation, computational chemistry (DFT)
- 🌱 Currently building: **ENodorIM**, an interactive simulator of human olfaction
- 📍 Strasbourg, France · from Azerbaijan 🇦🇿

### 🚀 Featured projects

| Project | What it does |
|---|---|
| [**pyionics**](https://github.com/kammmran/pyionics) | Python library to download, clean and convert NIST ILThermo ionic liquid data · `pip install pyionics` |
| [**ENodorIM**](https://github.com/kammmran/ENodorIM) | From molecule to smell: olfaction simulator driven by measured odorant-receptor data · [live](https://kammmran.github.io/ENodorIM/) |
| [**ILQSPR**](https://github.com/kammmran/qspr-il-density-refractive-index) | Consensus XGBoost models for density & refractive index of ionic-liquid mixtures (R² 0.90–0.96) |
| [**marimo4obs**](https://github.com/kammmran/marimo4obs) | Obsidian plugin to run marimo reactive Python notebooks inside your vault |
| [**collab-kit**](https://github.com/kammmran/collab-kit) | Contribution rules for humans and AI coding assistants (AGENTS.md, templates, checks) |
| [**PyDOOM-DL**](https://github.com/kammmran/PyDOOM-DL) | DOOM-style raycaster in pure numpy, built as a reinforcement-learning environment |
| [**mylovely-mice**](https://github.com/kammmran/mylovely-mice) | Agent-based browser simulation of a mouse colony with genetics · [live](https://kammmran.github.io/mylovely-mice/) |
